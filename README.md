# JobFit

### A smart job application, interview tracking and career improvement platform for freshers.

JobFit is a Java-based web application designed to help freshers manage their job search journey in one place.

Instead of maintaining job applications, interview rounds, scores and improvement areas separately, JobFit brings the complete journey together — from applying for a job to tracking interview performance and identifying areas that need improvement.

---

## Project Overview

Finding a job as a fresher involves applying to multiple companies, remembering interview rounds, tracking application status, preparing for different rounds and understanding why an interview was successful or unsuccessful.

JobFit is designed to solve this problem by providing a centralized platform where users can:

- Track companies and jobs they have applied to
- Manage application status
- Record interview rounds
- Track interview scores
- View interview performance
- Analyze performance by interview type
- Identify areas that need improvement
- Follow their complete interview journey

The long-term goal is to evolve JobFit from a simple job tracker into a personalized career and job-readiness platform.

---

## Key Features

### 1. User Authentication

- User registration
- User login
- Session-based authentication
- Logout functionality
- Personalized dashboard

---

### 2. Job Application Tracking

Users can store information about their job applications including:

- Company name
- Job role
- Role description
- Location
- Work mode
- Application date
- Job source
- Job URL
- Application status
- Personal notes

---

### 3. Interview Round Management

Users can create and manage interview rounds for each application.

Examples:

- Aptitude
- Technical
- Coding
- Communication
- HR
- Managerial
- Other/custom rounds

Each round can contain:

- Round number
- Round name
- Round type
- Interview date
- Status
- Score
- Skills tested
- What went well
- Improvement notes
- Round description
